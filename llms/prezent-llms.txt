# Prezent Platform API

> The Prezent Platform API exposes Prezent's AutoGenerator, Template Converter, Audiences, Themes, and File-upload services behind a single uniform JSON HTTP API. Every documented endpoint uses the same `{ "success": true, "data": {...} }` / `{ "success": false, "data": null, "error": {...} }` envelopes, a stable error-code catalog, Bearer-token authentication, and a consistent async polling pattern. It is designed to be agent-friendly, and ships a hosted Model Context Protocol (MCP) server, webhooks, and Server-Sent Events streaming.
